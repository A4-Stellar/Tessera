# Holders

<ApiEndpoint method="GET" path="/assets/:id/holders" description="Holder list with balances, sorted by balance descending." />

Returns every address that is on the asset's compliance allowlist **and** holds a
positive balance. The asset-token contract does not enumerate holders directly, so
the indexer derives this from the allowlist intersected with balances.

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `id` | number | Registry id |

**Query parameters** (all optional)

| Name | Type | Notes |
|------|------|-------|
| `offset` | integer | Skip the first N holders. Default: `0`. |
| `limit` | integer | Page size. Default: `50`; maximum: `100`. |

**Response schema** (per holder):

| Field | Type | Notes |
|-------|------|-------|
| `address` | string | Holder account |
| `balance` | string | Base units (`i128`) |
| `share_percent` | number | Percent of total supply, 0–100 (2 dp) |

**Example**

```bash
curl $API_BASE_URL/assets/1/holders
```

```json
[
  {
    "address": "GAIQGTOBTTLLDJ4SWGGESM7UWJ2DI4K3ZNHUSHPDKJL2IE5FKY3BSRAA",
    "balance": "1000000",
    "share_percent": 100.0
  }
]
```

**Errors**

Returns `404` with `{ "error": "not_found", … }` when the asset id is unknown. An
asset with holders but none currently holding a positive balance returns an empty
array `[]`.

<CalloutBox variant="note">
Holders are sorted by balance, largest first. `share_percent` is computed from
`balance / total_supply` at index time, so it reflects the most recent 10-second
refresh.
</CalloutBox>

<ApiEndpoint method="GET" path="/v1/holders/:address/portfolio" description="Automated Asset Portfolio Performance & Return Tracking API (issue #162)." />

Computes historical portfolio performance metrics (Time-Weighted Return, Net Present Value, Internal Rate of Return) for an investor account address across all tokenized real-world assets.

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `address` | string | Investor account public key |

**Query parameters** (all optional)

| Name | Type | Notes |
|------|------|-------|
| `start_date` | string | RFC3339 timestamp filter for evaluation window. |
| `end_date` | string | RFC3339 timestamp filter for evaluation window. |
| `discount_rate` | number | Annualized discount rate for NPV (default: `0.05` for 5%). |

**Response schema**

- `summary`: Aggregate portfolio market valuation, total assets held, cash inflows/outflows, and net invested capital.
- `holdings`: Per-asset token balances, share percentages, implied unit prices, and market values in USD.
- `dividends`: Historical dividend payouts received by the investor.
- `performance`: Time-Weighted Return (TWR) taking into account cash inflows and outflows, Net Present Value (NPV), and annualized Internal Rate of Return (IRR).
- `time_series`: Chronological valuation and cash flow points formatted for chart rendering.
